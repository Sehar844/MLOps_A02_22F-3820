# Milestone 0 — Docker Fundamentals and Environment Setup

## Objective
The objective of this milestone was to understand Docker fundamentals and prepare the development environment for containerized application deployment.

## Tasks Completed

1. Set up and verified the Docker development environment.
2. Practiced Docker image and container management.
3. Worked with Docker commands to create, inspect, start, stop, and remove containers.
4. Tested containerized services using port mapping.
5. Explored Docker images and container lifecycle operations.
6. Verified container status and application accessibility.

Screenshots for Milestone 0 are included in the assignment screenshots folder.

## Outcome
The Docker environment was prepared and fundamental Docker operations were practiced. This provided the foundation for building and running the machine learning prediction service in subsequent milestones.
