# Breast Cancer Triage Service — MLOps Assignment 02

**Course:** Machine Learning Operations (MLOps)  

## 1. Project Overview

This project implements a containerized breast cancer prediction service using a machine learning model. It provides a REST API built with FastAPI and uses Redis to maintain a persistent prediction counter.

The project demonstrates dataset versioning with DVC, automated model training, Docker image creation, multi-container orchestration with Docker Compose, and publishing images to Docker Hub.

## 12. Run the Application with Docker Compose

Validate the Compose configuration:

```powershell
docker compose config
```

Build and start the API and Redis services:

```powershell
docker compose up -d --build
```

Check the running containers:

```powershell
docker compose ps
```

View application logs:

```powershell
docker compose logs -f
```

To stop the services:

```powershell
docker compose down
```

To stop the services and remove the Redis volume:

```powershell
docker compose down -v
```

**Note:** Removing the Redis volume resets the stored prediction counter.

## 13. API Endpoints

Once the Compose stack is running, the API is available at:

`http://localhost:8002`

| Endpoint | Method | Purpose |
|---|---|---|
| `/` | GET | Root endpoint |
| `/health` | GET | Health check |
| `/docs` | GET | Interactive Swagger API documentation |
| `/model/info` | GET | Model information |
| `/stats` | GET | Redis prediction statistics |
| `/predict` | POST | Breast cancer prediction |

Open Swagger documentation:

`http://localhost:8002/docs`

Use the interactive documentation to submit a prediction request with the API's required input fields.

Check the service health:

```powershell
Invoke-RestMethod http://localhost:8002/health
```

Check prediction statistics:

```powershell
Invoke-RestMethod http://localhost:8002/stats
```

## 14. Redis Integration

Redis is used to maintain the prediction counter.

- The API connects to Redis using the Docker Compose service name `redis`.
- Each successful prediction request increments the Redis counter.
- The `/stats` endpoint reports Redis availability and the current prediction count.
- A named Docker volume stores Redis data persistently.
- The counter survives a normal `docker compose down` followed by a restart.
- Removing the volume with `docker compose down -v` resets the counter.

## 16. Clean-Room Deployment Using Docker Hub

The clean-room test verifies that the published image can be pulled and run without building it from the source code.

The clean-room Compose configuration uses the published Docker Hub image and does not contain a local Docker build instruction.

Pull the required images:

```powershell
docker compose -f docker-compose.hub.yml pull
```

Start the clean-room stack:

```powershell
docker compose -f docker-compose.hub.yml up -d
```

Check container status:

```powershell
docker compose -f docker-compose.hub.yml ps
```

Check API health:

```powershell
Invoke-RestMethod http://localhost:8003/health
```

Open the API documentation:

`http://localhost:8003/docs`

Check Redis statistics:

```powershell
Invoke-RestMethod http://localhost:8003/stats
```
